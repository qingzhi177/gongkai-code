# Memory System v1.6 快速使用指南

## 访问 Dashboard

浏览器打开: http://localhost:8001/

## 功能页面

### 1. Stats (统计)
- 查看 L0 消息数量和 L1 记忆数量
- 实时更新统计信息

### 2. Config (配置)
- **Provider 管理**:
  - 查看所有 API 供应商
  - 新增/编辑/删除 provider
  - 设置激活的 provider 和模型
  
- **Narrative 配置**:
  - 选择专用于生成 Narrative 的 provider
  - 选择模型 (建议使用强力模型如 claude-opus-4-6)

### 3. Narrative (记忆总结) ⭐ 新功能
**首次使用前请先在 Config 页面配置 Narrative 模型！**

- **生成 Narrative**:
  1. 点击"生成 Narrative"按钮
  2. 系统读取所有 L1 memories
  3. 使用 Narrative 模型生成月相式总结
  4. 每个 memory 标注重要性 (⚫ 重要 / ⚪ 次要)

- **月相进度条**:
  - 显示当前 memory 数量占满月的比例
  - 满月约 300 条 memories

- **历史记录**:
  - 查看所有历史 Narrative
  - 点击查看详情
  - 删除过时的 Narrative

### 4. Updates (更新检查) ⭐ 新功能
- **检查需要更新的 memories**:
  - 系统根据设定周期检查长期未更新的 L1
  - 显示需要更新的 memories 列表
  
- **配置更新周期**:
  - 默认 30 天
  - 可自定义周期
  
- **标记已更新**:
  - 点击"标记已更新"按钮
  - 更新 last_updated 时间戳

### 5. Summary (摘要)
- 查看最近的 L1 memories
- 按时间倒序排列

## 典型工作流程

### 第一次使用
1. 访问 Config 页面
2. 确认 Provider 配置正确
3. 配置 Narrative 专用模型
4. 进入 Narrative 页面，生成第一个总结

### 日常使用
1. **查看统计**: Stats 页面查看记忆增长
2. **生成总结**: 定期在 Narrative 页面生成新总结，了解记忆全貌
3. **检查更新**: Updates 页面查看哪些 memories 需要重新审视
4. **配置调整**: Config 页面切换不同的 provider 或模型

### 维护建议
- **每周**: 生成一次 Narrative，追踪记忆演变
- **每月**: 检查 Updates 页面，更新过时的 memories
- **每季度**: 清理历史 Narratives，只保留关键节点

## API 快速参考

### Narrative
```bash
# 生成 Narrative
curl -X POST http://localhost:8001/narrative/generate

# 获取最新 Narrative
curl http://localhost:8001/narrative/latest

# 获取历史
curl http://localhost:8001/narrative/history

# 删除
curl -X DELETE http://localhost:8001/narrative/{id}
```

### 配置
```bash
# 获取所有 providers
curl http://localhost:8001/config/providers

# 获取 Narrative 配置
curl http://localhost:8001/config/narrative

# 设置 Narrative 配置
curl -X PUT http://localhost:8001/config/narrative \
  -H "Content-Type: application/json" \
  -d '{"provider_id": 2, "model": "claude-opus-4-6"}'
```

### 更新检查
```bash
# 检查需要更新的 memories
curl http://localhost:8001/updates/check

# 标记已更新
curl -X POST http://localhost:8001/updates/mark \
  -H "Content-Type: application/json" \
  -d '{"memory_id": 123}'

# 获取/设置更新周期
curl http://localhost:8001/updates/config
curl -X PUT http://localhost:8001/updates/config \
  -H "Content-Type: application/json" \
  -d '{"interval_days": 30}'
```

## 故障排查

### Dashboard 无法访问
```bash
# 检查服务状态
ps aux | grep "python main.py"

# 查看日志
tail -f /tmp/memory-service.log

# 重启服务
cd /home/qingzhi/memory-system/services/memory-service
source venv/bin/activate
kill <pid>
nohup python main.py > /tmp/memory-service.log 2>&1 &
```

### Narrative 生成失败
1. 检查是否配置了 Narrative 模型 (Config 页面)
2. 确认 API Key 正确
3. 查看日志: `tail -f /tmp/memory-service.log`

### API Key 加密问题
确保环境变量 `CONFIG_SECRET_KEY` 已设置：
```bash
# 生成新密钥
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

# 添加到 .env
echo "CONFIG_SECRET_KEY=<your-key>" >> .env
```
